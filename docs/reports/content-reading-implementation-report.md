# 노드·로드맵 전체 읽기

구현일: 2026-11-16

## 목적과 동작

노드와 로드맵 설명의 두 줄 미리보기는 유지하고, 카드 더블클릭으로
편집 양식을 열지 않고 전문을 읽는 경로를 제공한다. 별도 `전체 읽기` 버튼은 표시하지 않는다.
카드 선택·노드 이동·연결·로드맵 가로 드래그는 기존 조작을 유지한다.

- 노드·로드맵 카드의 본문을 더블클릭하면 전체 읽기를 연다. 설명이 짧은 항목도 지원한다.
- 한 번 클릭은 기존 선택·편집을 수행한다. 마우스 클릭은 300ms 동안 더블클릭과 구분하여
  첫 클릭에 편집 패널이 열려 두 번째 클릭 대상이 이동하는 문제를 방지한다.
- 더블클릭은 선택·편집을 실행하지 않고 노드의 캔버스 확대도 차단한다.
- 키보드에 의한 클릭은 즉시 처리하며 카드에 초점을 둔 상태에서 `Alt+Enter`로 읽기를 연다.
- 터치는 같은 카드를 두 번 탭하면 연다. 스와이프·드래그·다중 터치는 읽기와 구분한다.
- 데스크톱에서는 카드 옆에 읽기 창을 열며 화면 가장자리에 맞춰 위치를 조정한다.
- 읽기 창은 캔버스 밖에 표시하므로 그래프 확대율과 관계없이 같은 글자 크기로 읽는다.
- 본문의 줄바꿈을 유지하고 텍스트 선택·복사를 지원한다. 긴 본문만 내부 스크롤한다.
- `크게 보기`는 중앙의 넓은 모달 읽기 창을 열며 `작게 보기`로 돌아간다.
- 900px 이하 화면에서는 넓은 모달 읽기 창을 사용한다.
- `편집`은 해당 노드·단계의 기존 편집기를 열고 제목 입력으로 초점을 옮긴다.
- Escape·닫기 버튼은 원래 카드로 초점을 돌린다. 기본 읽기 창은 바깥 클릭으로도 닫힌다.
- 카드가 가려지거나 화면 영역에서 사라지면 닫고, 프로젝트·결과 전환이나 저장·조회 중에는
  이전 본문을 다시 열지 않는다.

## 상태와 구현 범위

`ContentReaderProvider`는 읽을 항목의 종류·ID·호출 카드만 로컬 상태로 관리하고,
본문은 현재 결과에서 조회한다. 미저장 노드·단계 수정도 그대로 표시한다.
읽기를 여닫거나 확대해도 선택 항목, 노드 좌표, 캔버스 위치, 로드맵 스크롤,
편집 기록, 저장 상태, 결과 버전을 변경하지 않는다.

별도 버튼과 잘림 측정 코드는 제거했다. 더블클릭·키보드·두 번 탭으로 읽기를 열고,
노드 드래그·로드맵 가로 드래그·카드 선택과 구분한다.
읽기 창은 네이티브 dialog와 body 포털을 사용하며 모달의 키보드 초점을 제한한다.
추가 패키지, API·DB 계약 변경, AI 호출은 없다.

## 검증

- Web 단위 테스트 87개 통과.
- 신규 Chromium E2E 6개 통과: 노드 전문·선택·복사·확대·키보드·초점 복원,
  로드맵 스크롤·미저장 편집 보존·편집기 연결, 바깥 클릭·숨긴 항목·버전 전환,
  실제 모바일 터치 두 번 탭과 화면 경계, 노드·단계 더블클릭과 단일 클릭 구분·확대 방지·지연 선택 취소.
- 전체 Chromium E2E 46개 통과: 실제 PostgreSQL 저장·복원·동시 저장 충돌,
  기존 노드·연결·로드맵 편집, 드래그·검색·실행 취소·패널 조절·모바일 회귀 포함.
- TypeScript 검사·ESLint·production build 통과.
  빌드는 `build/ux-content-reading-web` 복사본에서 수행했다.
- 데스크톱·390×844 모바일 캡처를 직접 확인했다.
  결과와 캡처는 `playwright-report/index.html`에서 확인한다.
