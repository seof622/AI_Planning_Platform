# 편집 실행 취소·다시 실행과 캔버스 위치 유지 — 2026-10-26

노드·연결·로드맵 편집을 저장 전에 되돌리고, 화면 배치가 바뀌어도 보고 있던 그래프 위치를 유지한다.

## 동작

- 상단 작업 줄에 실행 취소·다시 실행 아이콘을 제공한다. Ctrl/⌘+Z로 실행 취소,
  Ctrl+Y 또는 Ctrl/⌘+Shift+Z로 다시 실행한다. 입력란과 편집 가능한 텍스트의 기본 실행 취소는 가로채지 않는다.
- 노드 필드·위치·추가·삭제, 연결 추가·재연결·유형 변경·삭제,
  로드맵 필드·순서·관련 노드·선행 참조·추가·삭제를 하나의 기록으로 관리한다.
- 같은 텍스트 필드의 연속 입력은 포커스를 벗어나거나 다른 작업을 수행할 때까지 묶는다.
  마우스 드래그는 이동을 마칠 때 기록하며 키보드 노드 이동도 되돌릴 수 있다.
- 노드 삭제의 연결·로드맵 참조 정리와 단계 삭제의 선행 참조·번호 정리를 함께 복구한다.
  복구 시 존재하는 노드·단계만 선택하고 잘못된 참조를 만들지 않는다.
- 작업 기록은 최근 100개까지 메모리에 유지한다. 새 편집은 다시 실행 기록을 지우며,
  검증에 실패하거나 실제 내용이 바뀌지 않은 조작은 기록하지 않는다.
- 편집 저장 후에도 기록을 유지하고 마지막 저장 내용과 현재 편집을 비교한다.
  저장한 내용을 되돌리면 미저장, 다시 실행해 저장 내용과 같아지면 저장됨으로 표시한다.
  결과 메타데이터·버전 ID·동시 저장 토큰과 입력 초안은 실행 취소 대상에 포함하지 않는다.
- 새 프로젝트·결과 버전·생성·복원·초기화는 기록을 비운다. 버전 조회·생성 실패는 기존 기록을 유지한다.
  저장·조회·생성·복원 중에는 기록 이동과 편집을 차단하며 저장 충돌 정책은 유지한다.
- 일반 편집, 상세 편집기 열기·닫기, 패널 크기 조절과 집중 보기 전환에서는
  확대율과 그래프 좌표계의 화면 중심을 유지한다. 숨겨진 영역의 0 크기는 무시한다.
- 새 결과는 React Flow가 노드 위치와 크기를 반영한 뒤 한 번 맞춘다.
  노드 수가 같거나 그래프가 숨겨진 상태로 결과를 바꿔도 처음 보일 때 맞춘다.
  캔버스의 `전체 보기` 버튼으로 언제든 전체 노드를 다시 표시한다.
- React Flow의 측정값과 이동 중 위치는 화면 내부에서 관리하며 저장 데이터나 실행 취소 기록에 넣지 않는다.

## 검증

- Web 단위 테스트 76개 통과. 텍스트 입력 묶음, 삭제 참조 복구, 연결·순서·참조 편집 재실행,
  무효·동일 편집 제외, 100개 기록 제한, redo 제거, 저장 후 기준 상태 비교,
  저장 충돌 토큰 유지, 비동기 작업 차단과 실패 시 기록 보존을 포함한다.
- 전체 Chromium E2E 28개 통과. 실제 PostgreSQL을 사용한 저장·새로고침·버전 복원·동시 저장과
  드래그 실행 취소·다시 실행 후 저장을 포함한다.
- 새 브라우저 테스트 5개는 텍스트 기본 실행 취소, 공통 편집 기록과 단축키,
  패널·집중 보기 전환 중 확대율·중심 유지, 같은 노드 수의 버전 전환과 숨김 후 자동 맞춤,
  모바일 배치, 키보드 노드 이동을 검증한다.
- 기존 패널 열기·실패 복구 검사는 자동 맞춤 대신 명시적인 전체 보기 또는 현재 화면 위치 보존을 확인하도록 변경했다.
- TypeScript 검사, ESLint와 production build 통과. 빌드는 개발 서버와 분리한
  `build/undo-viewport-web` 복사본에서 수행했다.
- 브라우저 실행 결과와 화면 캡처는 `playwright-report/index.html`, 실행 안내는 `tests/e2e/README.md`에 있다.

검증 과정에서 새 버전의 위치가 바뀌어도 React Flow의 측정 준비 상태가 복구되지 않아
자동 맞춤이 대기하는 문제를 발견했다. 화면의 노드 상태에 측정값을 유지하고,
React Flow가 새 노드를 반영한 뒤 자동 맞춤하도록 수정해 같은 노드 수의 버전 전환을 재검증했다.

## 범위

로컬 실행 취소 기록과 확대율·중심은 새로고침 후 복원하지 않는다.
저장된 결과 버전과 화면 배치 설정의 기존 복원은 유지한다.
다음 우선순위는 관련 노드·로드맵 단계 강조와 노드 검색·유형 필터다.
