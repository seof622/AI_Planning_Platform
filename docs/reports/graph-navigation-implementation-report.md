# Graph·Roadmap 연결 탐색과 노드 검색 — 2026-10-27

노드와 로드맵 단계의 관계를 화면에서 확인하고, 관련 노드나 검색 결과로 바로 이동한다.

## 동작

- 노드를 선택하면 관련 로드맵 단계에 왼쪽 표시선과 `관련` 문구를 표시한다.
  노드 이름과 관련 단계 개수를 안내하고 첫 관련 항목이 목록 안에 보이게 한다.
- 단계를 선택하면 관련 노드를 점선 테두리로 강조한다. 실제 선택과 구분하고 접근성 이름에도 관련 여부를 표시한다.
- 로드맵의 읽기 목록과 상세 편집기에 관련 노드 이동 버튼을 제공한다.
  현재 존재하는 참조만 표시하며 미저장 이름·참조 변경을 바로 반영한다.
- 관련 노드나 검색 결과를 누르면 노드를 선택하고 측정된 크기를 기준으로 화면 중심에 둔다.
  현재 확대율이 0.85보다 작으면 0.85로 올리고, 해당 노드에 키보드 초점을 둔다.
  일반적인 선택·편집은 기존 확대율·중심 유지 원칙을 따른다.
- 로드맵 집중 보기에서는 함께 보기로 바꾸고, 필터가 이동할 노드를 가리면 검색·유형 조건을 초기화한다.
  새 결과 자동 맞춤보다 명시적인 노드 이동을 우선하고 이전 결과의 이동 요청은 적용하지 않는다.
- 캔버스 상단 검색 아이콘에서 이름과 유형을 함께 적용한다. 이름은 앞뒤 공백·대소문자·전각 표기 차이를 정규화한다.
  결과 목록은 이름이 같아도 ID별로 제공하며 Enter로 버튼을 실행할 수 있다.
- 일치하지 않는 노드와 해당 노드에 연결된 선을 화면에서 숨긴다.
  필터 상태·검색 결과 수·결과 없음·초기화를 표시하고, 필터가 선택한 노드를 가리면 `선택한 노드 표시`를 제공한다.
  `전체 보기`는 현재 표시 중인 노드에 맞추며 표시할 노드가 없으면 비활성화한다.
- 검색·필터 변경은 화면을 자동 맞춤하지 않는다. 노드 이름 변경·삭제·실행 취소 후에는 현재 내용으로 검색 결과와 관련 표시를 갱신한다.
- 탐색·필터는 화면 내부 상태로 관리한다. 저장·Markdown 내보내기는 기존 전체 Graph·Roadmap을 사용하고,
  탐색 자체는 미저장 상태·입력 초안·실행 취소 기록·서버 버전을 만들지 않는다.
- 저장과 보기 전환에서는 필터를 유지한다. 새 프로젝트·결과 버전·생성·복원·초기화에서는 지운다.
  조회·생성 실패는 기존 필터와 편집을 유지하고, 비동기 작업 중에는 탐색 버튼과 검색 입력을 비활성화한다.

## 검증

- Web 단위 테스트 82개 통과. 검색 정규화·유형 교차 조건·중복 이름의 ID 구분·비변경성,
  검색 초기화·결과 이동·로딩 차단, 관련 단계 강조와 편집 없는 노드 이동을 포함한다.
- 전체 Chromium E2E 35개 통과. 실제 PostgreSQL 저장·새로고침·버전 복원·동시 저장 충돌,
  기존 실행 취소·위치 유지·화면 배치·실패 복구·내보내기 회귀 검사를 포함한다.
- 새 탐색·검색 E2E 7개는 양방향 강조·중심 이동·키보드 초점, 검색·유형 교차 조건과 연결 숨김,
  결과 없음·초기화·화면 위치 유지, 숨겨진 노드로 이동과 미저장 편집 보존,
  이름 변경·삭제·실행 취소에 따른 갱신, 버전 조회 실패·성공 후 필터 수명을 검증한다.
- 저장·Markdown 내보내기 검사에서 숨겨진 노드와 연결·로드맵이 모두 포함되고,
  저장 및 저장 후 실행 취소에도 필터가 유지되는지 확인했다.
- 1600×1000 데스크톱, 1024×768 작은 데스크톱, 390×844 모바일에서 강조·검색 팝업·이동 캡처를 확인했다.
  모바일·작은 데스크톱의 수평 넘침과 검색 결과 버튼의 Enter 실행도 검증했다.
- TypeScript 검사, ESLint와 production build 통과. 빌드는 개발 서버를 유지하는
  `build/graph-navigation-web` 복사본에서 수행했다.
- 실행 결과와 화면 캡처는 `playwright-report/index.html`, 실행 안내는 `tests/e2e/README.md`에 있다.

## 범위

이름 검색과 유형 필터는 해당 결과 화면에서만 유지하며 브라우저 저장소에 기록하지 않는다.
검색은 노드 이름을 대상으로 하며 설명·전체 문서 검색은 포함하지 않는다.
