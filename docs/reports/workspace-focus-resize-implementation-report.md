# 집중 보기와 패널 크기 조절 — 2026-10-21

고정된 화면 비율 대신 작업에 필요한 영역을 넓혀 볼 수 있게 했다.
상단의 아이콘 도구에서 함께 보기, 그래프 집중 보기, 로드맵 집중 보기를 전환하고 계획 입력을 접는다.

## 동작

- 집중 보기에서는 선택한 결과 영역이 가용 높이를 사용한다. 그래프·로드맵과 입력 폼을
  언마운트하지 않아 선택, 미저장 변경, 세부 조건 펼침과 미니맵 설정을 유지한다.
- 입력 패널을 접으면 결과 영역이 넓어진다. 빈 화면의 계획 입력 버튼은 접힌 패널을
  펼치고 첫 입력란에 초점을 옮긴다. 결과가 없을 때는 함께 보기를 사용한다.
- 데스크톱 경계선에서 입력 너비(260–420px), 상세 편집 너비(280–420px),
  그래프 높이 비율(25–75%)을 조절한다. 그래프·로드맵에는 각각 최소 높이를 둔다.
- Pointer Events의 포인터 캡처를 사용해 마우스·터치 드래그를 처리한다.
  경계선은 키보드로 초점을 받을 수 있고 방향키, Shift+방향키, Home/End로 조절한다.
  경계선을 두 번 클릭하면 해당 크기만 기본값으로 돌린다.
- 화면 배치 초기화는 보기·입력 접기·세 크기를 기본값으로 되돌리며 편집은 유지한다.
- 보기, 접기와 크기는 브라우저의 `plannote.workspace-layout.v1` 설정에 저장한다.
  손상된 설정은 기본값을 사용하고 숫자 범위를 제한한다. 저장소 접근이 차단되어도
  현재 화면에서는 조절할 수 있다. 프로젝트 데이터나 결과 버전을 수정하지 않는다.
- 901–1280px 화면의 상세 편집은 기존 오버레이를 유지한다. 상세 너비 조절은
  1280px 초과 화면에서 제공한다. 900px 이하에서는 크기 조절선을 숨기고
  모바일 배치에 맞춘 고정 크기와 집중 보기·입력 접기 도구를 제공한다.
- 로드맵 집중 보기에서도 진행·실패 안내와 재시도를 로드맵 위에 표시한다.
  노드·단계 편집, 전체 저장, 버전 선택·복원과 충돌 처리 정책을 유지한다.

## 검증

- Web 단위 테스트 67개 통과. 저장된 설정의 잘못된 형식·알 수 없는 값·범위 초과 복구를 포함한다.
- 실제 PostgreSQL 저장·새로고침·버전 복원·동시 저장을 포함한 전체 Chromium E2E 23개 통과.
- 새 E2E는 보기 전환·입력 접기 후 편집과 선택 보존, 세 경계선 드래그,
  키보드·최소/최대 제한, 개별·전체 초기화, 새로고침 후 설정 복원을 검증한다.
- 1440×960 데스크톱, 1024×768 작은 데스크톱과 390×844 모바일의 넘침을 확인한다.
  로드맵 집중 보기에서도 버전 조회의 진행·오류·재시도를 검증한다.
- 모바일 캡처에서 도구줄이 편집기를 가리는 문제를 보완했다. 편집기를 도구줄 위에
  표시하고 제목 입력란의 실제 클릭·초점과 편집·닫기를 다시 검증했다.
- TypeScript 검사, ESLint와 production build 통과. 개발 서버를 유지하기 위해
  빌드는 `build/workspace-focus-web` 복사본에서 수행했다.

브라우저 캡처와 실행 결과는 `playwright-report/index.html`, 실행 안내는 `tests/e2e/README.md`에 있다.
새 배치 테스트는 fixture를 사용하며 AI 호출과 기존 프로젝트 변경을 수행하지 않는다.
