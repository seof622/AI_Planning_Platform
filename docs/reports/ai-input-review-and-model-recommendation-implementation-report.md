# AI 입력 검토 및 모델 추천 구현 보고서

검증일: 2026-11-26

사용자는 계획 주제만으로 검토를 시작할 수 있다. AI가 정리한 목표, 보완 질문,
진행 가정과 추천 근거를 확인하고, 답변을 반영해 다시 검토하거나 현재 정보로
진행한다. 최종 확인 화면에서 사용자가 확정한 입력·가정·모델로 계획을 생성한다.

검토, 모델 선택, 최종 확인, AI 실행, 품질 피드백은 PostgreSQL에 저장된다.
생성 결과에는 연결된 검토 및 실행 ID가 붙는다. 입력이나 모델이 변경되면
기존 확인으로 새 생성을 시작할 수 없다. 같은 요청의 재전송에는 기존 실행을
반환하고 실패한 실행은 명시적 재시도로 새 시도를 기록한다. 실행 완료와
상태 조회가 겹쳐도 완료 상태가 중단으로 덮어써지지 않는다.

프로젝트의 기존 직접 생성 요청은 HTTP 409로 검토 절차를 안내한다.
평가 도구는 비프로젝트 `/planning/generate`를 계속 사용하며 응답에
`executionOrigin: evaluation-direct`를 기록한다.

## 검증

- `npm run verify:node` 통과. Web 단위 테스트 96건, 평가 도구 테스트 8건, 타입 검사, 린트, 프로덕션 빌드를 확인했다.
- API 테스트 57건 통과. PostgreSQL의 Alembic 리비전 `20261124_0005` 적용과 동시 생성 시 결과가 한 번만 저장되는 것을 확인했다.
- Chromium E2E 52건 통과. 주제만으로 검토, 답변 반영, 최종 확인, 모델 선택, 피드백 기록, 모바일 배치, 입력 변경과 복구, 기존 편집·버전 기능을 확인했다.
- 실제 모델 호출에서 검토와 4개 생성 결과가 모두 성공했다. 각 생성 결과가 해당 프로젝트의 최신 결과로 조회되며 검토 ID와 실행의 결과 ID가 일치함을 확인했다.

| 호출 | 모델 | 경과 시간 | 전체 토큰 |
| --- | --- | ---: | ---: |
| 입력 검토 | gpt-5-mini | 30.2초 | 3,299 |
| 계획 생성 | gpt-5-mini | 35.7초 | 5,311 |
| 계획 생성 | gpt-5.6-luna | 14.3초 | 3,155 |
| 계획 생성 | gpt-5.6-terra | 9.7초 | 2,639 |
| 계획 생성 | gpt-5.6-sol | 11.9초 | 2,772 |

실제 호출은 책상 정리 계획 한 건으로 연결과 저장을 확인했다. 입력에 대상,
작업과 제약이 모두 포함되어 검토 질문은 0개였다. 모델별 품질 비교에는
여러 대표 입력과 동일 평가 기준이 필요하다. 요율은 설정하지 않아 비용을
미확인으로 기록했다. 다른 데스크톱의 Prompt 평가 변경은 이 작업 폴더에서
동기화 여부를 확인하지 못했다.

실제 호출 증빙은 로컬 `build/local-runtime/planning-review-smoke.json`에,
브라우저 결과는 `playwright-report/index.html`에 있다.
