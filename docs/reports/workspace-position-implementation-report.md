# 프로젝트별 마지막 작업 위치 복원

구현일: 2026-10-29

## 동작

- 앱을 다시 열면 마지막으로 정상 조회한 프로젝트의 최신 결과를 불러온다.
  해당 프로젝트가 목록에 없으면 첫 프로젝트를 선택한다.
- 프로젝트별 선택 노드 또는 로드맵 단계, 캔버스 중심과 확대율,
  로드맵의 가로 스크롤 위치를 같은 브라우저에 저장한다.
- 다른 프로젝트를 열었다가 돌아오거나 새로고침하면 같은 결과의 작업 위치를 복원한다.
  캔버스 중심을 그래프 좌표로 저장하므로 패널 너비가 달라도 보던 지점을 유지한다.
- 로드맵 집중 보기처럼 캔버스가 숨겨져 있으면 노드 측정과 화면 표시를 기다린 뒤 위치를 복원한다.
  명시적인 관련 노드 이동은 저장된 위치보다 우선한다.
- 재진입 시 선택 항목을 최신 결과와 대조해 존재하지 않는 노드·단계는 해제한다.
  결과 버전이 바뀌면 새 그래프에 자동 맞춤하고 로드맵 가로 위치는 초기화한다.
- 프로젝트 조회가 실패하면 마지막 성공 프로젝트와 기존 위치 기록을 보존한다.
  재시도 성공 후에만 마지막 프로젝트를 갱신한다.
- 잘못된 JSON·좌표·확대율은 무시하고, 브라우저 저장소 접근 차단이나 용량 부족에도 탐색은 계속 동작한다.

## 저장 범위

`plannote.last-project.v1`에 프로젝트 ID를 기록하고,
`plannote.workspace-position.v1:<projectId>`에 결과 ID·선택 ID·화면 좌표만 기록한다.
계획 본문이나 미저장 편집 데이터는 저장하지 않는다. 이 기능은 같은 브라우저 범위이며
기기 간 동기화, 과거 버전 자동 재선택, 미저장 편집·실행 취소 기록 복원은 포함하지 않는다.
탐색 상태 저장은 결과 편집 상태나 서버의 버전 이력을 변경하지 않는다.

## 검증

- Web 단위 테스트 87개 통과. 프로젝트별 기록 분리, 부분 갱신, 잘못된 저장값,
  새 버전·삭제 항목과 저장소 차단을 검증하는 테스트 5개를 추가했다.
- 새 Chromium E2E 5개 통과. 프로젝트 왕복·새로고침, 노드·단계 선택과 두 영역의 위치,
  숨긴 캔버스, 새 결과의 자동 맞춤, 조회 실패·재시도와 저장소 차단을 검증했다.
- 전체 Chromium E2E 40개 통과. 실제 PostgreSQL 저장·새로고침·버전 복원·동시 저장 충돌,
  기존 검색·실행 취소·패널 크기 조절과 모바일 화면의 회귀 검사를 포함한다.
- TypeScript 검사·ESLint·production build 통과.
  빌드는 개발 서버를 유지하도록 `build/workspace-position-web` 복사본에서 수행했다.
- 실행 결과와 화면 캡처는 `playwright-report/index.html`, 실행 방법은 `tests/e2e/README.md`에 있다.
