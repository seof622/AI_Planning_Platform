# 작업 화면 UI 정리 — 2026-10-19

글꼴을 실제로 로드하고 입력창·버튼·카드의 공통 스타일을 정리했다.
화면 전체가 길어지고 그래프 위에 로드맵이 겹치던 배치를 화면 안에서 구분되는 작업 영역으로 바꿨다.

## 시각 구성

- 밝은 회색 배경, 흰색 작업 패널과 그린 포인트를 사용한다.
- Pretendard의 기본 굵기로 본문을 표시하고 제목과 버튼에만 중간 굵기를 적용한다.
- 일반 입력창은 8px, 작업 패널은 14px 모서리를 사용한다. 노드와 로드맵의 기본 브라우저 입력창도 공통 스타일로 바꿨다.
- 본문·폼·라벨의 크기와 행간, 제목 간격, 버튼 높이를 공통 기준으로 정리했다.
- 유형별 노드 색과 우선순위 표시는 유지하며 선택 상태와 키보드 포커스를 구분한다.

## 화면 배치

- 상단에 앱 이름, 현재 프로젝트와 편집 저장 상태를 표시한다.
- 데스크톱 사이드바는 독립적으로 스크롤되며 전체 페이지를 불필요하게 늘리지 않는다.
- 그래프는 위쪽, 로드맵은 아래쪽의 독립된 패널에 배치한다. 각 로드맵 카드 안에서 긴 편집 내용을 스크롤할 수 있다.
- 넓은 화면에서 노드 편집기는 별도 열에 열린다. 좁은 화면에서는 닫을 수 있는 오버레이로 표시한다.
- 패널이나 화면 크기가 바뀌면 그래프를 다시 맞춰 노드가 편집기 뒤로 잘리지 않도록 한다.
- 미니맵은 캔버스 헤더에서 표시·숨기기를 선택한다.
- 모델 선택 안내와 생성 세부 정보는 펼쳐 볼 수 있게 정리했다.

## 글꼴 출처

- [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard), v1.3.9의 원본 가변 WOFF2를 사용한다.
- 글꼴과 원본 SIL Open Font License를 `apps/web/public/fonts/`에 함께 포함한다.
- CSS가 로컬 파일을 로드하므로 실행·빌드 시 외부 글꼴 CDN에 의존하지 않는다.
- 원본 파일: `https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`

## 검증

- Web Vitest 36개, TypeScript 검사와 ESLint 통과.
- 기존 Graph·Roadmap 편집, 드래그·재연결, 저장·복원과 두 탭 충돌 E2E 5개 통과.
- UI E2E 2개에서 로컬 글꼴 로딩, 데스크톱 화면 넘침·패널 겹침 방지, 모바일 화면 너비와 편집기 접근을 검증했다.
- 노드 편집기 열림에 따른 그래프 맞춤과 미니맵 표시·숨기기도 확인했다.
- 1440×960 데스크톱과 390×844 모바일 화면을 렌더링해 확인했다.
- 로컬 글꼴 파일을 포함한 독립 복사본에서 Next.js production build를 통과했다.
- API 계약·데이터 저장 방식과 의존성 버전은 변경하지 않았다.

브라우저 보고서는 `playwright-report/index.html`의 `workspace-desktop`, `workspace-mobile` 첨부에서 확인할 수 있다.
