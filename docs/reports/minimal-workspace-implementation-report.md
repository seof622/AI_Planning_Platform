# 작업 화면 텍스트 최소화 — 2026-10-21

상시 설명과 도구 이름이 결과 내용과 경쟁하던 부분을 줄였다. 입력값과 결과 내용은 읽을 수 있게 두고,
보조 동작은 선형 SVG 아이콘과 짧은 이름으로 표현한다.

## 화면 변경

- 새 프로젝트는 `+`, 버전 정보·비교는 이력, Markdown 내보내기는 다운로드,
  미니맵은 지도, 닫기는 `×`, 단계 삭제는 휴지통 아이콘으로 표시한다.
- 저장은 아이콘과 **저장**, 생성은 **계획 생성 / 다시 생성**, 추가는 **+ 노드 / + 단계**로 표시한다.
  상세 동작 이름과 전체 저장 범위는 접근성 이름·설명, 툴팁에 유지한다.
- 세 저장 영역에서 반복되던 전체 저장 범위 문장을 제거한다. 캔버스의 정보 아이콘을 눌러 연결 방법,
  결과 전체 저장 범위와 입력 초안의 자동 저장을 확인할 수 있다. 모바일에서도 탭으로 연다.
- 헤더의 정상 상태 배지와 브랜드 부제, 입력·캔버스의 영어 장식 제목과 중복 소개 문장을 제거한다.
  결과 저장 상태는 체크·원·경고 아이콘과 **저장됨 / 미저장 / 저장 중 / 저장 실패**로 줄인다.
- 입력 초안 상태는 입력 제목 옆의 작은 아이콘과 **초안**으로 표시한다. 전체 상태는 툴팁과
  스크린리더 상태 알림으로 제공한다. 실제 저장 오류와 재시도는 입력 패널에 계속 표시한다.
- 필수 입력은 `*`, 해야 할 일의 필수·선택 토글은 체크·원으로 표시한다.
  생성에 부족한 입력은 문장으로 안내하고, 정상 생성 가능 상태의 반복 설명은 화면에서 숨긴다.
- 결과 미반영 안내는 **입력 변경됨**으로 줄인다. 전체 의미와 새 버전 생성 안내는 툴팁과
  생성 버튼의 접근성 설명에 유지한다.
- 버전 선택은 **vN · 최신 / 출처**로 줄이고, 날짜·모델·Prompt 정보는 버전 상세에서 제공한다.
- 로드맵의 반복되는 제목·설명 라벨을 숨기고 필드의 접근성 이름을 유지한다.
  관련 노드·선행 단계와 우선순위·작업량은 명시적인 이름으로 유지한다.
- 모바일에서는 버전 선택·이력·내보내기를 한 줄에 배치한다.

## 구현과 검증

외부 아이콘 패키지나 이미지 자산 없이 공통 SVG 아이콘과 저장 버튼을 사용한다.
아이콘 자체는 보조 기술에서 숨기고, 동작의 접근성 이름과 상태 알림을 유지한다.
도움말의 Escape·바깥 클릭 닫기, 프로젝트 이동 시 편집 확인, 삭제 확인과 저장 충돌 정책을 유지한다.
회전 아이콘은 사용자의 모션 감소 설정을 따른다.

- 단위 테스트 47개, TypeScript 검사, ESLint 통과.
- 데스크톱 1440×960, 작은 노트북 1024×768, 모바일 390×844 배치와 실제 캡처 확인.
- 아이콘 버튼의 접근성 이름, 저장 범위 설명, 클릭으로 여는 도움말과 오류 재시도 검증.
- 숨긴 필드 라벨이 가로 스크롤 영역 밖으로 빠져나오지 않도록 필드의 위치 기준을 지정했다.
- 실제 저장·복원·두 탭 충돌·PostgreSQL 동시 저장·내보내기·배치를 포함한 전체 E2E 11개 통과.
- 최종 Next.js production build 통과. 개발 서버와 API의 정상 응답도 확인했다.

빌드 복사본은 `build/minimal-workspace-web`을 사용한다. 개발 서버는 localhost:3000에서 유지한다.
