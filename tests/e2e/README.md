# Browser Editing E2E

실제 Chromium, Next.js, FastAPI와 PostgreSQL을 연결해 편집 기능을 검증한다.
AI 생성 대신 canonical fixture를 전용 프로젝트에 저장하므로 OpenAI 호출은 없다.

## 실행

```powershell
npm ci
npx playwright install chromium
docker compose up -d --build api postgres
npm run test:e2e
```

Web은 localhost:3000, API는 localhost:8000을 사용한다. Playwright가 Web을
자동 시작하며 이미 실행 중이면 해당 서버를 사용한다. 다른 데이터베이스를
사용하려면 Docker Compose 환경을 먼저 구성한다.

현재 Windows에서 네이티브 SWC 로드가 차단되는 경우, 이 저장소의 Next 버전과
동일한 WASM 컴파일러를 로컬 설치한 뒤 실행할 수 있다.

```powershell
npm install --no-save @next/swc-wasm-nodejs@15.5.22
```

이 명령은 package.json과 lockfile을 변경하지 않으며 `npm ci` 후에는 다시
설치해야 한다. Next 버전을 변경할 때는 컴파일러 버전도 맞춰야 한다.

## 검증 범위

- Node 이름·설명·분류·우선순위 변경과 실제 마우스 드래그
- 새 버전 저장 후 새로고침을 통한 필드와 위치 복원
- Roadmap 제목·설명·우선순위·작업량 편집과 유효한 단계 순서 변경
- 선행 단계보다 먼저 이동하는 순서 변경 차단
- Graph와 Roadmap 동시 편집 저장, 원본과 중간 버전 보존
- 과거 원본 선택 및 새 최신 버전으로 복원
- 브라우저 예외와 console error 검사
- 버전 번호·원본/편집본/복원본 출처와 필드별 비교 표시
- 미저장 편집 상태의 버전 이동 취소
- 두 탭의 저장 충돌, 편집본 보존·명시적 저장·최신 버전 불러오기
- 복원 충돌 후 미리보기 보존과 사용자 확인 후 재시도
- PostgreSQL에서 동일 최신 버전에 대한 동시 요청 2건 중 1건만 성공
- 노드 추가와 유형 변경, 실제 마우스 드래그 연결·유형이 달라도 같은 시작·끝 노드의 중복 연결 차단
- 연결선 라벨 선택·유형 변경, 끝점 드래그 재연결·삭제 후 새로고침 복원 및 이미 연결된 노드 쌍으로의 재연결 차단
- 노드 삭제 확인 취소·승인, 연결·로드맵 참조 정리와 과거 버전 보존
- 로드맵 단계 추가·삭제, Graph 노드 연결·해제, 선행 단계 선택에 따른 자동 정렬
- 순환 의존성 차단, 삭제 확인 취소·승인과 선행 참조 해제, 빈 로드맵 저장·재추가·원본 복원
- 1440×960 데스크톱에서 세로·가로 넘침과 그래프·로드맵·편집 패널 겹침 방지
- 390×844 모바일 배치, 로컬 Pretendard 글꼴 로딩, 미니맵 표시·숨기기와 명시적인 전체 보기
- 실제 Markdown 파일 다운로드, UTF-8 한글 파일명과 요구사항·요약·노드·연결·로드맵 내용
- 미저장 노드 편집 포함·편집 상태 보존, 과거 버전 내보내기와 결과 없는 상태의 비활성화
- 내보내기가 편집 저장·복원 요청이나 추가 버전을 만들지 않는지 확인
- 프로젝트 선택·추가의 상단 배치, 버전·내보내기의 작업 줄 배치와 캔버스 내부 그래프 도구
- 새 프로젝트·버전 정보 창의 Escape·바깥 클릭 닫기, 접은 세부 조건의 입력값 보존
- 입력 스크롤·모델 안내 펼침 중 생성 버튼 유지, 1024×768 화면과 모바일 팝업의 넘침 방지
- 입력 초안 저장 실패·재시도, 새로고침 후 미반영 입력 안내와 결과 편집 저장 상태 구분
- 생성에 부족한 입력 안내와 세 저장 버튼의 노드·연결·로드맵 전체 저장 범위 확인
- 아이콘 도구의 접근성 이름·클릭 동작, 짧은 저장 버튼과 정보 팝업의 저장 범위 설명
- 재생성·버전 조회 중 기존 결과 표시, 실패 시 선택·미저장 편집·입력 유지와 명시적 재시도
- 프로젝트 조회·생성의 로딩 구분, 모델·이력의 개별 재조회와 성공한 생성의 중복 호출 방지
- 모바일 오류 안내 초점과 재시도 접근, 빈 화면에서 첫 입력으로 이동
- 10개 단계 가로 카드 배치·마우스 드래그·모바일 터치 스와이프와 드래그 시 오선택 방지, 키보드 선택과 편집기 닫기 후 카드 초점·표시 복원
- 노드·단계 공통 상세 영역 전환 시 미저장 변경 보존, 모바일 단계 편집기 배치
- 함께·그래프·로드맵 보기 전환과 입력 접기 후 입력·선택·편집·미니맵 유지
- 입력·상세 너비와 그래프·로드맵 비율의 드래그·키보드 조절, 범위 제한과 초기화
- 새로고침 후 화면 설정 복원, 모바일 집중 보기와 로드맵 집중 보기의 진행·실패·재시도
- Graph·Roadmap 공통 실행 취소·다시 실행, 연속 입력 묶음과 입력란의 기본 실행 취소 유지
- 드래그·키보드 노드 이동 되돌리기, 다시 실행 후 실제 DB 저장·새로고침 복원
- 편집·패널 조절·집중 보기 전환 중 그래프 확대율·중심 유지와 같은 노드 수의 새 결과 자동 맞춤
- 모바일 실행 취소·다시 실행, 새 편집의 redo 제거와 버전 전환 후 로컬 기록 초기화
- 노드·단계 양방향 관련 항목 강조, 목록·편집기의 관련 노드 이동과 키보드 초점
- 이름·유형 교차 필터, 연결 숨김·결과 없음·초기화와 필터 전후 화면 위치 유지
- 로드맵 집중 보기에서 숨겨진 노드로 이동, 미저장 편집 유지와 탐색의 실행 취소 기록 제외
- 이름 변경·삭제·실행 취소 후 검색과 관련 단계 갱신, 버전 조회 실패 시 필터 유지와 성공 시 초기화
- 필터로 숨긴 노드를 포함한 전체 편집 저장·Markdown 내보내기, 저장·실행 취소 후 필터 유지
- 390×844 모바일·1024×768 작은 데스크톱의 검색 팝업 배치와 관련 노드 이동
- 프로젝트 A→B→A 전환·새로고침 후 선택 노드·단계, 캔버스 중심·확대율과 로드맵 가로 위치 복원
- 숨긴 캔버스의 지연 복원, 사라진 프로젝트·선택 항목과 새 결과 버전 처리
- 조회 실패 시 마지막 성공 프로젝트·위치 보존, 잘못된 브라우저 데이터·저장소 차단에서도 탐색 유지

성공 시 DB 이력 JSON과 최종 화면을 HTML 보고서에 첨부한다. 실패 시
스크린샷과 trace를 보존한다. 보고서는 `playwright-report/index.html`에 있다.

기능 테스트 5개는 각각 `Editing E2E <UTC timestamp>` 프로젝트를 하나 새로 만든다.
UI 배치·저장 안내·집중 보기 테스트 9개, 실행 취소·캔버스 위치 테스트 5개, 연결 탐색·검색 테스트 7개,
로딩·복구 테스트 7개, Markdown 내보내기 테스트 2개와 작업 위치 복원 테스트 5개는 API fixture를 사용하며
DB에 프로젝트를 추가하거나 변경하지 않는다.
전체 40개 테스트 실행은 5개 프로젝트를 만들며, 편집 흐름은 5개 버전, Graph 구조 편집 흐름은
4개 버전, Roadmap 구조 편집 흐름은 6개 버전, 두 탭 충돌 흐름은 5개 버전,
동시 저장 흐름은 2개 버전을 남긴다. 기존 프로젝트를 수정하거나
테스트 데이터를 자동 삭제하지 않는다. 실패한 실행은 중간 결과를 남길 수 있다.

Markdown 다운로드와 화면 배치만 확인하려면 다음을 실행한다. 이 검증은 실제 OpenAI나 DB를 사용하지 않는다.

```powershell
npm run test:e2e -- tests/e2e/markdown-export.spec.ts tests/e2e/ui-layout.spec.ts
```

연결 탐색·검색만 확인하려면 `npm run test:e2e -- tests/e2e/graph-navigation.spec.ts`를 실행한다.

작업 위치 복원만 확인하려면 `npm.cmd run test:e2e -- tests/e2e/workspace-position.spec.ts`를 실행한다.
